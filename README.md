# se-login-signup

A simple front-end project with Login and Sign Up pages built using HTML and CSS.

## Files

- `login.html` — Login page with User ID and Password fields
- `signup.html` — Sign Up page with First Name, Last Name, User ID, and Password fields
- `styles.css` — Shared stylesheet for both pages
- `README.md` — This file

## How to Run

Download the project and open `login.html` in any web browser. No server needed.

## Commits

1. `Add HTML structure` — Created login.html and signup.html
2. `Add CSS styling` — Created styles.css
3. `Complete README` — Added project documentation
